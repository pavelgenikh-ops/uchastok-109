# Публикация на GitHub Pages и QR-код

## Разовая настройка (15 минут)

**1. Создать репозиторий на GitHub**

Зайти на github.com → New repository → имя, например `uchastok-109`.
Видимость: **Public** (на бесплатном плане Pages работает только у публичных
репозиториев). Не добавлять README — он уже есть здесь.

**2. Привязать и отправить**

В папке приложения (репозиторий уже создан и первый коммит сделан):

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/uchastok-109.git
git push -u origin main
```

При первом push GitHub попросит войти — проще всего через браузер.

**3. Включить Pages**

Репозиторий → Settings → Pages → Source: **Deploy from a branch** →
Branch: `main`, папка `/docs`. Save.

Через минуту страница будет по адресу:
`https://ВАШ_ЛОГИН.github.io/uchastok-109/`

**4. QR-код**

Открыть приложение по этому адресу и нажать кнопку **QR** — код строится
на текущий адрес. Отсканировать телефоном, при желании сохранить картинку
и разослать.

## Обновление после правок

```
1. АРХИВ.bat      — (по желанию) свежий переносимый архив
2. ПУБЛИКАЦИЯ.bat — собирает папку docs из текущей версии
3. git add -A && git commit -m "что изменилось" && git push
```

Через минуту адрес отдаёт новую версию — **на всех устройствах сразу**:
и на телефоне, и на компьютере, и у всех, кому дана ссылка. Отдельно ничего
переносить не нужно. В шапке приложения показана дата сборки — по ней видно,
свежая ли версия открыта.

## Что публикуется, а что нет

В папку `docs` попадает только то, что нужно браузеру: `index.html`, `js`, `lib`,
`data`, `models`, `utils`. **Не публикуются**: `node.exe` (93 МБ), рабочие
скрипты проверок, папка `экспорт`, запасные модели машин, служебные заметки.

## Если репозиторий должен быть закрытым

GitHub Pages на бесплатном плане всегда публичен: адрес не индексируется
поисковиками, но открыть его может любой, кто знает ссылку.

Закрытый вариант — **Cloudflare Pages + Access**: тот же бесплатный хостинг,
но вход по одноразовому коду на почту, список допущенных адресов задаёте вы.
Публикация так же из папки `docs`, QR работает так же.
