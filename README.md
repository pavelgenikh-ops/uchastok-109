# Благоустройство участка 109 — 3D

Интерактивный дизайн-проект благоустройства: СНТ «МАДИО Озерки», участок № 109,
кад. 47:07:0518004:14, Ленинградская обл., Всеволожский р-н, массив Токсово.

Геометрия участка построена по исполнительной съёмке (205 отметок, координаты
углов МСК), рельеф — сетка 0,5 м, спецификация объёмов считается из самой модели.

## Как открыть

**В браузере:** опубликованная версия — GitHub Pages (адрес в настройках репозитория,
раздел Pages). Открывается на компьютере и на телефоне, ничего ставить не надо.

**Локально:** распаковать архив приложения и запустить `START.bat` — поднимется
локальный сервер и откроется браузер. Для локального запуска нужен `node.exe`,
он лежит рядом в переносимом архиве (в репозиторий не кладётся: 93 МБ).

## Что умеет

- Три варианта дизайна: планировка, материалы, наполнение зон — у каждого своё
- Слои, спецификация объёмов, баланс земляных работ
- Высотные отметки от чистого пола 1 этажа (клавиша **H**), замер в любой точке
- Размеры участка (клавиша **D**)
- Дневной и вечерний режим со светильниками
- Экспорт альбома PDF, карандаш для набросков
- **Замечания по модели**: долгое нажатие пальцем на телефоне ставит метку,
  замечания выгружаются таблицей и снимками
- Перенос проекта одним JSON: «Проект → JSON» и «Загрузить JSON»

## Структура

```
index.html      интерфейс и стили
js/design.js    ВСЁ проектное решение в координатах участка (u,v)
js/geo.js       система координат, рельеф, геометрия лестниц
js/build.js     сборка сцены
js/spec.js      спецификация — считается из геометрии
js/notes.js     замечания по модели
data/site.json  границы, отметки и деревья из исполнительной съёмки
```

Подробности — в `ПРОЧТИ.md`, перенос и обновление — в `ПЕРЕНОС.md`.
